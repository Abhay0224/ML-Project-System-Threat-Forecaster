# ML-Project-System-Threat-Forecaster

**Goal:** Predict a system’s probability of being infected by malware using telemetry data from antivirus reports.

Each row in the dataset corresponds to a unique machine identified by `MachineID`. The `target` column indicates whether malware was detected on the machine. The goal is to predict `target` for unseen test data.

---

## 📘 Project Overview

This project demonstrates **machine learning for proactive malware detection**:

- Uses system telemetry features collected from antivirus reports.
- Predicts the probability of system infection.
- Helps forewarn systems before they are compromised.

---

## 🛠️ Tech Stack

- **Python 3.x** – Programming language
- **Jupyter Notebook** – Interactive notebook environment
- **Pandas & NumPy** – Data manipulation
- **Scikit-learn** – Machine learning models
- **Matplotlib & Seaborn** – Data visualization
- **Kaggle** – Dataset source and experimentation

---



> ⚠️ Dataset is not included due to size/privacy. Download it from Kaggle: [System Threat Forecaster](https://www.kaggle.com/competitions/System-Threat-Forecaster)

---


## 🔍 Key Features

- Exploratory Data Analysis (EDA) of telemetry data
- Data preprocessing and feature engineering
- Machine learning model training and evaluation
- Prediction of malware infection probability
- Visualizations for feature importance and insights

---

## 📊 Model Performance

- Model accuracy: **62.58%**
- Predicts malware infection probability for each machine.
- Feature importance identifies key telemetry metrics.
- Performance can be improved with hyperparameter tuning and additional feature engineering.
